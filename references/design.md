# 版式和编辑入口

画幅为16:9。原项目使用LaTeX Beamer；本包保留此格式，并另制可编辑PowerPoint模板。模板是个人衍生版，不表示学校官方发布。

| 角色 | PowerPoint | Beamer | 用途 |
| --- | --- | --- | --- |
| 广工红 | `#C30D23` | `#C30D23` | 封面横幅、目录强调、标题线、页脚、致谢 |
| 深红 | `#A50B1E` | `#960A1B` | 次级层次 |
| 淡红 | `#FCF0F2` | `#FBEFF1` | 强调区、公式底色 |
| 正文 | `#232323` | `#252525` | 正文和表格 |
| 次级文字 | `#696969` | `#666666` | 图注、来源、占位说明 |
| 页面 | `#FFFFFF` | `#FFFFFF` | 内容页背景 |

主色在两种格式中一致，辅助色按渲染效果有轻微变体。深浅变体是本模板设计选择，并非学校官方辅助色。以实际模板文件为各格式排版依据，勿在不必要时整体重建。

封面：上方官方横式校徽与校名，中央红色通栏，白色题目，下方胶囊形姓名与学院、导师、日期。内容页：左上标题、细红横线、白底正文、底部三段页脚。目录：左侧红白区域与大标题，右侧分项列表。致谢：白底，标题、副标题及汇报人信息均为广工红文字，保留原有文字与排版；Beamer 中的官方校徽保持原位置与比例。

字体优先选择中文黑体与无衬线英文字体。PowerPoint 使用 Microsoft YaHei；在无此字体的系统上安装可用字体或在母版中统一替换为 Noto Sans CJK SC，不假定所有平台都会等宽替换。Beamer 提供系统字体检测及 TeX Live 的 Fandol 回退，不捆绑商业字体。

## 个人信息

`scripts/init_deck.py` 可以同时填写两种格式的标题、姓名、学院、导师和日期。未传入的字段保持模板占位文字。

- Beamer：改 `profile.tex`，版式在 `config.tex`，内容在 `main.tex` 或 `starter.tex`。
- PowerPoint：复制 `.pptx` 修改样例页，或用 `.potx` 创建演示文稿。在“视图 → 幻灯片母版”进入对应版式修改页眉页脚，需要统一字体时使用“替换字体”。特定页的正文和图表在普通编辑视图修改。

标题过长先换行或精简；内容过多时拆页。不要用整体缩小字号掩盖溢出。图文页的灰框是待替换区域，不是实验结果。三线表的待填写项不参与真实指标比较。
